About This Compendium

Unlike wikis that paraphrase and interpret, DCC Codex anchors every entry to the author's exact words. Click any entity to see every passage across all eight books where it is physically described.

Visualizations are generated by Imagen 3 using only details present in the source text — no artistic interpretation, no fan-art style. The prompt used to generate each image is shown alongside the passages that informed it.

All text is © Matt Dinniman. This is a fan project for readers who need more help visualizing the alien landscapes and bizarre creatures Carl encounters in the dungeon.
